# Tests Directory Organization

This directory contains all test files, test data, and example scripts for the bwamem package.

## Directory Structure

```
tests/
├── test_*.py              # pytest test files
├── example.py             # Example script: basic usage
├── quick_demo.py          # Example script: quick demo
├── process_paired_reads.py # Example script: paired-end processing
├── create_demo_files.py   # Script to generate demo test data
├── test_data/             # All test data files organized by category
│   ├── demo/              # Demo FASTA/FASTQ files and index
│   │   ├── demo_reference.fasta
│   │   ├── demo_reads_R1.fastq
│   │   ├── demo_reads_R2.fastq
│   │   └── demo_index.*   # Generated demo index files
│   ├── reference/         # Subset reference for matesw tests
│   │   └── ref.mk.subset.* # BWA index files (79 sequences)
│   └── rRNA/              # rRNA reference and index files
│       ├── rRNA.fa
│       ├── rRNA.*         # BWA index files
│       └── rRNA_index.*   # Additional index files
└── README_TEST_ORGANIZATION.md  # Detailed test documentation
```

## Test Files

### Automated pytest Tests

- **`test_bwamem.py`** - Basic BWA functionality tests
- **`test_cigar_insertion.py`** - CIGAR operation tests
- **`test_fastx_reader.py`** - FASTX file reading tests
- **`test_input_validation.py`** - Input validation tests
- **`test_matesw.py`** - mem_matesw functionality tests
- **`test_paired_mapping.py`** - Paired-end mapping workflow tests
- **`test_visualization.py`** - Alignment visualization tests

### Manual/Debug Scripts

- **`test_matesw_direct.py`** - Standalone script for manual testing/debugging

## Running Tests

By default, pytest is configured to show output (`-s` flag), so you'll see all `print()` statements and test progress in real-time.

### Run all tests:
```bash
pytest tests/
```

### Run specific test files:
```bash
pytest tests/test_matesw.py
pytest tests/test_visualization.py
```

### Run with verbose output (default, already enabled):
```bash
pytest tests/test_matesw.py -v
```

### Suppress output (if you want quieter tests):
```bash
pytest tests/ --capture=yes
# or
pytest tests/ -q
```

## Test Data

### Demo Data (`test_data/demo/`)
- Small reference and read files for basic functionality tests
- Generated by `create_demo_files.py` if not present
- Used by `test_paired_mapping.py`

### rRNA Data (`test_data/rRNA/`)
- rRNA reference sequences and pre-built indexes
- Used by example scripts

### Subset Reference (`test_data/reference/`)
- Minimal reference containing 79 sequences (900KB total)
- Used for matesw and visualization tests
- Suitable for GitHub (much smaller than full reference)

## Example Scripts

Example scripts in the `tests/` root demonstrate various use cases:
- `example.py` - Basic usage examples
- `quick_demo.py` - Quick demonstration
- `process_paired_reads.py` - Processing paired-end reads

## Notes

### Visualization Functions

The visualization functions (`Alignment.visualize()` and `visualize_paired_alignment()`) are currently implemented in Python for functionality. **These should ideally be implemented in C code for better performance**, especially when visualizing many alignments. The current Python implementation works but may be slower for large-scale operations.

See `bwamem/libbwa.py` for implementation details and TODO notes.

## Organization Principles

1. **Test files** (`test_*.py`) - All pytest test files in root of `tests/`
2. **Example scripts** - Demonstration scripts in root of `tests/`
3. **Test data** - All test data organized in `test_data/` subdirectories by category
4. **Generated files** - Indexes created during tests stored with their test data
5. **Documentation** - README files for organization and usage
